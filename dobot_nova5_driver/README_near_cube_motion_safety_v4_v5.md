# V4/V5 近立方体翻底路径预检与持物故障保护

针对“`bottom_near_cube_motion_preflight` 通过、夹紧后短抬升却报接近肘奇异点，随后 `GetPose=-2` 持续刷屏”的情况，两版共用 `near_cube_motion_safety.py`。

## 夹紧前检查

- 初始 Tool Rx −45° 转动先检查后执行。
- 短抬升、Tool Rx +90°、回到支撑面和恢复抓取姿态，均沿笛卡尔路径采样。使用上一点关节解继续求解；中间点可用下面的本地逆解，段末仍调用控制器 InverseKin 并以该关节解作为 `JointNear`。每个点检查关节限位余量、解的连续性及 IK/FK 一致性。
- 某个采样间隔的关节变化超过 20° 时，先检查候选点的奇异余量，再对该间隔二分采样，最多细分 4 层。末端再次以中间点的关节解为 `JointNear` 求解。只有细分后每一步均不超过 20°、且所有检查通过才接受；不能用放宽阈值代替检查。每次路径检查最多 256 次 IK 查询，包括细分尝试。
- 构造归一化雅可比矩阵，筛查奇异风险。平移除以特征长度 0.5 m，转动以弧度计算，最小奇异值 `sigma` 无量纲。默认优先采用下面的控制器校验本地计算；需要回退时使用原来的 PositiveKin 数值微分。
- 风险检查不通过，沿用现有 30→25→20 mm 抬升候选；仍失败则开爪恢复直立，尝试一次直立抓取、抬升 20 mm、User X−60 mm、放回支撑面的搬移。搬移路径本身也必须先通过同样检查。搬移后重新检查翻底，不能无限搬移。
- PositiveKin 查询异常、控制器报警或取消操作会终止预检，不会被当作几何风险去尝试搬移。

检查是保守的数值筛查，不能替代控制器的实际轨迹规划、奇异点保护或碰撞检测，也不保证提前识别所有控制器报警。`JointNear` 只约束查询解，实际 MovL 仍由控制器规划。采样会增加近立方体翻底前的查询时间，应通过阶段日志测量真机耗时；侧码直抓不增加这部分检查。

## 参数

下表的平移步长、角度步长、sigma 阈值和 `fast_jacobian`、`fast_ik` 开关可直接通过 V4/V5 D435 launch 的同名参数设置。其余项为节点 ROS 参数，可在参数配置中设置。默认 0.025 为初始筛查阈值，尚未经本次故障位置的真机标定。

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| `bottom_near_cube_preflight_linear_step_m` | 0.005 | 平移采样最大间隔，m |
| `bottom_near_cube_preflight_rotation_step_deg` | 10.0 | 姿态采样最大间隔，度 |
| `bottom_near_cube_preflight_min_sigma` | 0.025 | 归一化雅可比最小奇异值下限 |
| `bottom_near_cube_preflight_fast_jacobian` | true | 启用控制器校验的本地雅可比；不匹配时自动回退 |
| `bottom_near_cube_preflight_fast_ik` | true | 已验证模型对中间点求本地逆解；逐点控制器 FK 复核，段末仍查询控制器 IK |
| `bottom_near_cube_preflight_joint_step_deg` | 20.0 | 相邻采样解的单关节最大变化，度；超限先细分，仍超限则拒绝 |
| `bottom_near_cube_preflight_length_scale_m` | 0.5 | 雅可比平移归一化长度，m |
| `bottom_near_cube_preflight_joint_margin_deg` | 2.0 | 关节限位内侧余量，度 |
| `bottom_near_cube_preflight_joint_limits_deg` | J1 ±360、J2 ±180、J3 ±160、J4/J5/J6 ±360 | 六组下限、上限，单位度，按 Nova5 配置 |

例如保持新默认值启动 V5：

```bash
ros2 launch dobot_nova5_driver cosmetic_box_single_arm_cycle_v5_d435.launch.py \
  bottom_near_cube_preflight_linear_step_m:=0.005 \
  bottom_near_cube_preflight_rotation_step_deg:=10.0 \
  bottom_near_cube_preflight_min_sigma:=0.025
```

V4 使用 `cosmetic_box_single_arm_cycle_v4_d435.launch.py`。原有抬升和搬移参数、角度及路径方向保持原值。

## 预检查询优化

旧方式在每个采样点需要一次控制器正解，另加六次扰动正解来计算雅可比。新方式通过只读 PositiveKin 查询获得串联关节的本次参考关系，使用独立的单轴和多轴查询验证，然后在本地计算完整雅可比。它使用空间坐标系的[指数积运动学公式](https://modernrobotics.northwestern.edu/nu-gm-book-resource/4-1-1-product-of-exponentials-formula-in-the-space-frame/)和[空间雅可比](https://modernrobotics.northwestern.edu/nu-gm-book-resource/5-1-1-space-jacobian/)，不依赖猜测的机器人尺寸，也不跨周期复用模型。

实机曾因约 0.001° 的模型角度差提前回退，完整预检仍查询 195 次正解。标定改为使用两组跨度最高 30° 的参考关节值查询正解，减少小角度差分对数值误差的放大；接近单位旋转轴的估计再做归一化，并继续通过独立查询校验。**这些是输入 PositiveKin 的数学参考值，不是机械臂运动指令**，查询值也保持在配置关节范围内。原有 0.005 mm/0.0005° 校验阈值、20° 连续性限制和奇异阈值均未放宽。数值精度压力测试覆盖单精度位置、大幅旋转和四位小数姿态，不能代替实际控制器复测。

- 每个路径采样点仍向控制器查询正解，并额外审计一个关节的扰动正解；被审计的关节轮换覆盖六轴。允许的本地/控制器差异仅为 0.005 mm、0.0005°。
- 同一次翻底的初始 −45°、完整翻转及降高度/搬移候选共用本次已验证的数学模型。每段检查仍重新读取起点 FK，并重新查询全部 8 个独立校验点；校验通过才省去 12 次建模 FK。上一段的 FK/IK 查询结果不跨段缓存。控制器、User/Tool 索引或检查参数变化时使用单独模型；退出翻底或异常时清除，工作线程之间隔离。
- 复用模型在新起点校验不通过，会以当前起点重新建模。重新建模验证失败或路径中出现差异，就在本次翻底中停用模型，回退原来的六轴控制器数值微分。控制器查询错误和取消请求仍直接终止预检。
- 仅验证位姿时只计算正解；同一采样点的雅可比只计算一次，避免之前在模型校验中重复构造。
- 本地 `sigma` 距离原阈值不超过 0.020 时，使用原控制器数值微分复核后再决定。原来的 20° 连续性限制、路径采样密度、关节限位与持物故障保护均保留。
- 可以用启动参数 `bottom_near_cube_preflight_fast_jacobian:=false` 显式使用原方式。

### 中间采样点的本地逆解

实机完整路径预检 1.001 s 中，34 次 InverseKin 耗时 333.2 ms，73 次 PositiveKin 耗时 588.3 ms。进一步优化在已验证模型上使用[有界数值逆解](https://modernrobotics.northwestern.edu/nu-gm-book-resource/6-2-numerical-inverse-kinematics-part-2-of-2/)，从上一点的关节解出发做阻尼 Newton 迭代。每次迭代单关节最大 5°、最多 16 次，平移残差要求 ≤0.00001 mm、旋转残差要求 ≤0.00000573°；迭代过程也检查取消和关节余量。该残差只表示本地数学收敛，不能替代控制器验证。

- 只用于路径中间点。每个运动段的最终点始终调用控制器 InverseKin，细分后也保留该终点查询。
- 所有中间解仍查询真实控制器 FK，按原来的位姿一致性、模型精度、扰动审计、连续性和奇异余量规则检查。未通过控制器复核的本地解不会被采用。
- 不收敛、接近关节限位，或本地 sigma ≤阈值+0.020 时使用控制器 IK。模型校验失败、本地解实际位姿不符时，停用本次模型，再以原始上一点关节解查询控制器 IK 并重新检查；控制器查询故障或 Stop 直接中断。
- 相邻解超过 20° 的细分规则和 256 次逆解尝试上限仍生效。默认路径、运动速度、夹爪及持物异常处理沿用原流程。
- PositiveKin 查询缓存按 SDK 实际发送的六位小数关节值匹配，仅合并同一段检查中内容相同的只读请求。
- `bottom_near_cube_preflight_fast_ik:=false` 可关闭本地逆解，保留本地雅可比；关闭 `fast_jacobian` 也会使用控制器 IK。

日志包含 `FK_queries`、`local_J`、`controller_J` 和 `model`。`model=verified` 表示本次关系通过校验；`model=fallback(...)` 会包含退回原方式的原因。`model_reused=1` 表示本段通过重新校验后复用了模型。`local_IK`、`local_IK_attempts`、`local_IK_fallbacks` 分别记录通过复核的本地逆解候选数（包含随后被细分的粗采样候选）、尝试数及回退数。`IK_ms`、`FK_ms` 分别统计控制器查询耗时（包括排队等锁），`local_IK_ms` 是本地逆解时间，`other_ms` 为剩余时间，四项可相加。实际耗时仍以真机 `bottom_near_cube_motion_preflight` 日志为准；离线查询数下降不等于真机同比提速。

## 持物后的异常

短抬升、翻转、回到支撑面，以及备用搬移中的持物运动发生异常时，会锁定近立方体持物故障，关闭自动循环与自动恢复请求。运动中会尝试 Stop；控制器已经处于报警/碰撞模式时保留其停止状态。夹爪保持最后一次指令，不自动松爪、清错或搬移，也不进入普通抓取失败的自动回初始位流程。

人工妥善安置物料并全开夹爪后，才能再次执行回初始位：要求夹爪状态为到位、开度为最大行程的 95%–100%。这是恢复门槛，不能由软件证明物料已经被安全安置。进程重启后的人工检查仍然必要，内存中的故障锁定不会跨重启持久化。

循环发生故障或反馈显示控制器报警/碰撞时，暂停 D405 预跟踪和后台位姿转换，避免继续执行 GetPose。控制器恢复到已使能静止状态后，由后续显式启用预跟踪或视觉请求恢复处理。

## 验证和日志

离线测试覆盖独立解析运动学模型的可达但奇异位形、路径中途奇异、关节跳变/限位、FK 不一致、取消、降高度、一次搬移上限、查询故障不搬移，以及两版持物异常与重启门槛。测试不连接机器人。

真机验证关注 `sampled preflight passed` 的 `samples`、`minimum_sigma`、`maximum_joint_step` 和 `bottom_near_cube_motion_preflight` 耗时。`maximum_joint_step` 是接受路径的最大关节步长；`maximum_trial_joint_step` 包含被细分的粗采样尝试；`refinements`、`IK_queries` 可用于评估查询成本。细分后仍超限会记录关节编号、前后关节解及 `sigma`。若仍发生实际规划报警，应保留当时关节反馈、工具标定和报警目标，复核数值筛查与控制器的差异。

2026-10-20 实机日志出现粗采样步长 20.16°–25.15° 被直接记为“branch jump”。仅凭两个采样点的差值不能证明逆解换分支，因此加入上述细分。没有当时的完整关节解，不能仅根据该日志断定路径实际安全；奇异余量、限位和持物故障保护均继续生效。

V4/V5 的周期 `accounted_s` 改为计算阶段时间区间的并集，避免预检、搬移及其子阶段重复累计。各阶段的 `duration_s` 仍是包含子阶段的原始耗时，因此不能直接把所有明细相加当作总耗时。
